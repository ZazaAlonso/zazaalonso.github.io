# Licencias de Software

Las licencias en software indican los permisos que un programa otorga para su
uso o derechos respecto a acceso al código o la modificación de este.

Estas licencias entonces clasifican el software en dos grandes categorías:
- Privativo, si la licencia no otorga acceso a el codigo fuente
- Libre, si la licencia otorga acceso al código fuente.

## Software Privativo

Es el modelo usado por la mayoría de corporaciones y las grandes tecnológicas
para su beneficio económico. (Windows de Microsoft, videojuegos, la suite de
Office de Microsoft, la Creative Cloud suite de Adobe, etc.).

### Tipos

| Categoría         | Descripción                                                    |
| ----------------- | -------------------------------------------------------------- |
| Comercial         | De pago, usualmente bajo licencias de uso limitantes           |
| Shareware/Trial   | Pruebas gratuitas a software comercial                         |
| Freeware          | Software distribuido gratuitamente sin acceso al código fuente |

## Software Libre

Es un modelo basado en cuatro libertades que cualquiera debería tener respecto
al software:
    - **Libertad 0**: Ejecutar el programa como se desee, con cualquier propósito.
    - **Libertad 1**: Estudiar cómo funciona el programa y cambiarlo para que haga
      lo que se quiera.
    - **Libertad 2**: Redistribuir copias para ayudar a otro.
    - **Libertad 3**: Distribuir copias de las versiones modificadas a terceros,
      permitiendo que se beneficie de las mejoras.

### Tipos 

| Categoría         | Ejemplos de licencias         |
| ----------------- | ----------------------------- |
| Copyleft fuerte   | GPLv2, GPLv3                  |
| Copyleft débil    | LGPL, MPL 2.0                 |
| Permisivo         | MIT, BSD, Apache              |
| Dominio Público   | Unlicense, Creative Commons   |
