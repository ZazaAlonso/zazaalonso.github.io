# Licencias de Software

Las licencias en software indican los permisos que un programa otorga para su
uso o derechos respecto a acceso al código o la modificación de este.

Estas licencias entonces clasifican el software en dos grandes categorías:
- Privativo, si la licencia no otorga acceso a el codigo fuente
- Libre, si la licencia otorga acceso al código fuente.
